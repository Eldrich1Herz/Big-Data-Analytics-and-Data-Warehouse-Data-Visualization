Проблема с Java в WSL была решена так:

PySpark 4.1.1 требует Java 17 (class file version 61.0), а в WSL была установлена Java 11 (class file version 55.0).
Вместо обновления Java (что тоже возможно, но сложнее) мы понизили версию PySpark до 3.5.3, которая совместима с Java 11.
Установили PySpark 3.5.3 в виртуальное окружение (venv) через pip install pyspark==3.5.3.
Проверили: команда pyspark --version показала версию 3.5.3 и Java 11, тестовый код spark.range(5).show() отработал без ошибок.
